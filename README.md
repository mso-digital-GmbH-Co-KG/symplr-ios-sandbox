# symplr Ads SDK for iOS

The symplr Ads SDK for iOS, delivered as precompiled binaries through Swift Package Manager.

The integration guide is being written and will appear here.

## Requirements

- Xcode 27 or newer
- iOS 15 or newer

## Products

| Product | Purpose |
|---|---|
| `SymplrAdsSDK` | The SDK. Always required. |
| `SymplrAdsSourcepoint` | Consent through Sourcepoint. |
| `SymplrAdsFundingChoices` | Consent through Google Funding Choices (UMP). |
| `SymplrAdsAGMA` | AGMA measurement. |
